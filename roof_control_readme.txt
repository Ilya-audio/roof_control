Roof|control 1.1.2
Lightweight headphone monitoring system for REAPER (speaker emulation, true-stereo crossfeed with ITD, and AutoEQ headphone correction).

Requires REAPER 7.86+.

After installing:
1. Run Scripts/roof_control/roof_bubrik.lua (recommended: via SWS startup actions).
2. Place AutoEQ .txt profiles into Data/roof_control/phones_eq/.
